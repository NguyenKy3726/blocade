# Noto Sans

NotoSans-Regular.ttf được phân phối nguyên bản, hỗ trợ tiếng Việt.

- Nguồn upstream: https://github.com/notofonts/noto-fonts
- Bản sao lấy từ gói Debian fonts-noto-core có sẵn trong môi trường phát triển.
- Bản quyền Google; giấy phép SIL Open Font License 1.1 trong OFL.txt.
- SHA-256: `89c3c497f618fdaa0b2d1e98fef93582f28c71debd2c4a8cdf41f190ced2909d`.

Game nạp font từ thư mục này theo vị trí mã nguồn; không dùng font Windows/Linux cài ngoài và không tải font lúc chơi.
